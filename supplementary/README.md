## ?? How to Use

1. **Start with the 21-Day Prep Guide** - Follow the structured plan for comprehensive preparation
2. **Practice SQL Daily** - Work through SQL patterns and problems to build muscle memory
3. **Review Statistics Concepts** - Understand fundamentals before diving into advanced topics
4. **Practice Behavioral Questions** - Prepare your STAR stories for common questions
5. **Join the 2026 Challenge** - 8-week cohort program with real datasets in `challenge-2026/`
