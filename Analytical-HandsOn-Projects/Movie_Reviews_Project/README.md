# Movie Reviews / Ratings Exploratory Analysis

## 🎯 Project Overview

A beginner-friendly exploratory data analysis (EDA) project using the IMDB movie ratings dataset. This project builds foundational data analysis and visualization skills that translate directly to product analytics interviews.

## 📂 Project Contents

| File | Description |
|------|-------------|
| `Exploring-Movie-Ratings.ipynb` | Main analysis notebook |
| `README.md` | This file |

## 🔧 Skills Practiced

- **Data Cleaning:** Handling missing values, type conversions, outlier detection
- **Exploratory Data Analysis:** Descriptive statistics, distribution analysis, correlation
- **Visualization:** Matplotlib and Seaborn charts (histograms, scatter plots, bar charts)
- **Aggregation:** GroupBy operations, pivot tables, ranking

## 🎓 Learning Objectives

By completing this project, you will be able to:
- Load and clean a real-world dataset
- Compute descriptive statistics across categories (genre, year, rating)
- Visualize distributions and relationships between variables
- Identify trends and communicate findings clearly

## 📊 Suggested Dataset

**IMDB Movie Dataset** — available on [Kaggle](https://www.kaggle.com/datasets/harshitshankhdhar/imdb-dataset-of-top-1000-movies-and-tv-shows)

Fields: Title, Genre, IMDB Rating, Director, Gross Revenue, Runtime, Release Year, etc.

## 🚀 Getting Started

```bash
# Install dependencies
pip install pandas numpy matplotlib seaborn jupyter

# Launch the notebook
jupyter notebook Exploring-Movie-Ratings.ipynb
```

## 💡 Example Analysis Questions

1. What genres have the highest average IMDB ratings?
2. How have movie ratings changed over time?
3. Is there a relationship between runtime and rating?
4. Which directors consistently produce high-rated films?
5. How does gross revenue correlate with rating?
